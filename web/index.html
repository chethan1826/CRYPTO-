THE ALGORITHM

Built for a different era.

DES is a landmark in cryptography history. Understanding it helps explain how modern encryption evolved.

0164-bit block cipher

DES transforms data in fixed 64-bit blocks through 16 rounds of substitution and permutation.

0256-bit effective key

Eight bytes are supplied; eight parity bits leave 56 bits that control the encryption.

03Not secure today

A 56-bit key can be brute-forced with modern hardware. This demo is for learning only.
